# Task 4 Phase-aware Hybrid：冻结主网络 + 分阶段路径残差

这是独立实验 agent，不覆盖 `lsk_task4_agent` 的 Hybrid 1k 主模型，也不覆盖已经
冻结的 Path-aware 600 基线。当前推荐 checkpoint 为
`dqn_model_task4_phase.pt`：它从 Path-aware 600 继续训练 300 局，并加入分阶段
资源策略、战斗保护和定向防折返逻辑。

## 为什么这样修改

两局逐帧回放暴露出两个主要问题：

- seed 123 中 Hybrid 放置 45 枚炸弹、炸毁 23 个箱子，但 0 金币、0 击杀；
  金币可见时，靠近金币 23 次、远离 21 次、距离不变 18 次。
- seed 456 中 Hybrid 获得 2 金币和 2 击杀，但所有对手在第 261 步出局后，
  从约第 282 步开始在两个格子间折返 119 步。

原 23 维状态只包含目标方向和截断为 5 的曼哈顿距离，不能表达绕墙路径；
旧 VNext 虽提高炸弹效率，却让整个网络继续更新，导致击杀和生存策略被遗忘。

## Path-aware 结构

- 完整冻结已验收 Hybrid 1k 的 23 维网络（6086 个参数）。
- 新增一个仅 678 个可训练参数的小型 residual head；残差经过 `tanh` 限幅，
  只能有限修正原 Q 值，不能任意推翻已经很确定的战斗动作。
- 状态从 23 维扩展到 37 维，新增：
  - BFS 最短路径的四个第一步方向；
  - BFS 真实路径距离；
  - 路径目标是金币还是对手；
  - 存活对手数、剩余箱子数、可见金币数；
  - 放弹可命中目标数、自身逃生路线数；
  - 被炸弹覆盖的对手数及其剩余逃生路线数。
- 金币优先路径、追敌路径和残局炸箱路径使用真实 BFS，而不是曼哈顿方向。
- 使用 5-step return，使放弹动作能收到四步后爆炸产生的击杀和炸箱回报。
- 保留 Double DQN、target network、合法动作 mask、定时危险搜索、Huber loss
  和梯度裁剪。
- 学习率为 `2e-4`，训练从 epsilon `0.10` 开始；正式 Hybrid 权重始终冻结。

| 金币 | 199.0 | **297.0** | **+98.0（+49.2%）** |
| 击杀 | **41.0** | 34.5 | -6.5 |

## Phase-aware 300 最终优化

### 修改原因

seed 2026 暴露出 Path-aware 版本在场上仍有大量木箱时，会过早把对手作为 BFS
路径目标。这样虽然有机会击杀，但经常错过开荒金币，最终可能输给更早出局但金币
更多的对手。同时，单纯加强资源偏好又会削弱中后期击杀能力。

最终采用以下分阶段策略：

- 有可见金币时，路径规划首先寻找金币。
- 当剩余木箱多于 18 个时，若没有合适金币，则寻找可炸箱位置；木箱减少后才把
  对手作为主要路径目标。
- 开荒期只在金币距离不超过 6 步、最近对手距离大于 3、路径动作安全，而且该动作
  的 Q 值没有明显劣于当前最优动作时，才承诺沿 BFS 路径取金币。
- 残差网络追敌时缩小到 35%；对手相邻时完全关闭残差，直接使用原 Hybrid 战斗
  Q 值，避免资源学习覆盖已经学会的近战动作。
- 仅在确认出现 `A-B-A-B-A-B`、当前没有炸弹或爆炸并且目标不是对手时触发防折返，
  使用 BFS 的下一步打破循环。不会惩罚正常的即时撤退或战斗闪避。

### 最终对照结果

固定 seeds 123/456，每个种子 100 局，表中为两组的平均值：

| 指标 | Hybrid 1k | Path-aware 600 | Phase-aware 300 |
|---|---:|---:|---:|
| 得分 | 404.0 | 469.5 | **497.0** |
| 金币 | 199.0 | 297.0 | **317.0** |
| 击杀 | **41.0** | 34.5 | 36.0 |
| 自爆 | 29.0 | 27.5 | **23.0** |
| 炸箱 | 2756.5 | 3009.5 | **3101.0** |
| 无效动作 | 201.0 | 173.0 | **150.0** |
| 总步数 | 31862.5 | 30492.5 | 31160.0 |

相对 Path-aware 600，最终版本平均得分增加 `27.5`（`+5.9%`），金币增加
`20`，击杀增加 `1.5`，自爆减少 `4.5`，炸箱增加 `91.5`，无效动作减少
`23`。它没有恢复 Hybrid 1k 的全部击杀数，但修复了 Path600 的击杀下降趋势，
同时明显改善资源和生存表现。

seed 2026 的 30 局针对性筛选中，Path600 为得分 `126`、金币 `86`、击杀 `8`、
自爆 `13`；最终版本为得分 `143`、金币 `88`、击杀 `11`、自爆 `14`。这一种子
上仍存在 1 次额外自爆的随机波动，但得分、金币与击杀均改善。

### 消融选择

- 不启用金币承诺时，双种子平均得分更高（`503.5`），但金币只有 `301`，自爆
  `28`；资源与生存没有最终版本均衡。
- 全程强制金币承诺时，金币为 `305`，但得分降至 `480`、击杀降至 `35`、自爆
  增至 `32`，说明中后期不应继续硬性追金币。
- 最终只在木箱多于 18 个的开荒期启用受 Q 值约束的金币承诺。

## 历史失败消融

旧版 26 维 Dueling VNext 让整个网络继续训练。它改善单位炸弹产出，但双种子
平均得分只有 354、金币 224、击杀 26、生存率 54.5%，没有超过 Hybrid 1k。
相关 checkpoint 继续保留，仅用于报告消融：

